CodeMie workflow / TaskLite_AI_SDLC_Orchestrator

From enhancement request to tested, merged code

Ten AI assistants hand work to each other in a fixed order: requirements, backlog, design, code, review, deployment and QA. Every step that writes to Confluence, Jira or GitHub waits for a person to say yes.

Routing rules

The order is fixed. Three conditions decide where a request goes next.

enhancement_type = existing

Skip straight to Development

The Router asks one clarifying question. Changes to existing work skip requirements and design.

enhancement_type = new or unclear

Run the full path

BRD, backlog, implementation plan and solution design come before any code.

pr_approved and pr_merged

Review loop until merged

If either is false, PR Review Fix resolves the review threads and the PR goes back to review. This runs twice: after Development and after QA.

Guardrails

The same rules apply to every stage.

Nothing is written without a yes

No Confluence page, Jira issue, PR comment, approval or merge happens without explicit approval in chat.

Only the PR reviewer merges

The developer and fix assistants open and update PRs. Only PR Review can merge, and only when told to.

Approved scope only

Only what the BRD approves is planned or built. Create, view, complete/open and delete task keep working.

Traceable end to end

BRD, Epic, Stories, plan, design, code and tests link to each other. Artifacts carry the labels rahul_harma7 and codemie_capstone in Jira project EPMCDMETST.

Things to know

  • Shared skills. The skills belong to other projects. If an owner edits or removes one, an assistant's behavior can change.
  • Prompt wins over skill. Where a skill overlaps with an assistant prompt, such as the Jira writer's criteria style, the prompt takes precedence.
  • Jira project key. The backlog prompt spells it two ways, EPMCDMETST and EPM-CDME-TEST. The assistant is told to validate the real key.
  • Router is workflow-only. It has no standalone assistant. The standalone assistants in the repo do not carry these skills.
